# Python Beginner Projects

This repository contains small Python projects I built while learning Python fundamentals.
Each project focuses on practicing core programming concepts such as loops, functions, file handling, APIs, and basic algorithms.

These projects were created as part of my early learning journey in Python.

---

## Projects Included

| Project         | Description                                     |
| --------------- | ----------------------------------------------- |
| Calculator      | Simple CLI calculator for arithmetic operations |
| Countdown Timer | Timer that counts down to zero                  |
| Shopping Cart   | Simulates a basic shopping cart system          |
| Quiz Game       | Command line quiz game                          |
| Banking System  | Simple banking operations like deposit/withdraw |
| Slot Machine    | Basic slot machine game simulation              |
| Encryption Tool | Simple text encryption script                   |
| Alarm Clock     | Alarm tool using system time                    |
| API Project     | Example of fetching data from an API            |
| Cricket Game    | Simple cricket simulation                       |
| Mastermind      | Logic guessing game                             |
| Gesture to ADB  | Control ADB using gestures                      |
